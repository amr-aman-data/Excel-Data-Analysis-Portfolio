# Marketing Analytics Dashboard

## Project Overview

This project analyzes marketing campaign performance using Microsoft Excel.

The dashboard provides an overview of campaign performance and helps identify trends and differences across marketing campaigns.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Power Query
- Data Analysis

## Key Metrics

- Average Campaign Cost
- Average ROI
- Average Conversion Rate
- Average Customers / Conversions
- Cost per Customer / Conversion

## Dashboard

The dashboard presents key marketing performance indicators and provides insights into campaign effectiveness, customer conversions, and campaign costs.


## Key Analysis

The analysis focuses on comparing marketing campaign performance using ROI, conversion rate, campaign cost, and customer conversions.

It also helps evaluate the relationship between campaign spending and the number of customers generated.
